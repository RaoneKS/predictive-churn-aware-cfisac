# Corrected Professor Submission Package

This package uses the corrected four-policy, ten-seed simulation results.

Contents:
- `RESEARCH_RESULTS_REPORT.md`: corrected methods, results, interpretation, and limitations.
- `figures/`: 30 figures regenerated from corrected results and their manifest.
- `simulation_results/`: corrected aggregate/per-seed CSVs, 4,000 block rows,
  metadata, and per-seed decision traces.
- `PROJECT_README.md`: project overview copied from the earlier package.

Important:
- Results are simulation-based, not physical hardware measurements.
- QoS and tracking values are violation magnitudes, not counts.
- Energy is a simulation-model metric, not measured electrical power.
- Findings are descriptive and do not establish universal superiority or
  hard feasibility guarantees.
- The original submission package was preserved separately.
